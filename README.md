# Бюджетный калькулятор

## Описание классов и методов:

### Класс GUI:
- **Описание**: Графический интерфейс приложения.
- **Методы**:
  - `show_diagramm(app, action='undefined')`: Получение диаграммы действий (доходы/расходы) из JSON файла.
  - `show_income()`: Получение диаграммы доходов.
  - `append_income()`: Добавление записи с доходом и отображение актуальной диаграммы доходов.
  - `show_consumption()`: Получение диаграммы расходов.
  - `append_consumption()`: Добавление записи с расходом и отображение актуальной диаграммы расходов.
  - `clear_json()`: Очистка JSON файла.

### Класс WalletKeeper:
- **Описание**: Ядро приложения, обработка запросов и сохранение статистики.
- **Методы**:
  - `new_transaction(action:str = 'undefined', amount:int = 0, category:str = 'undefined', date:str = None)`: Создание новой транзакции и добавление её в историю.
  - `get_action_history(action:str, max_size:int = 10, month:str = None) -> list[tuple[str, int, str]]`: Получение истории действий в формате ("название", "количество", "% от всех операций в этой категории").
  - `load_histroy() -> None`: Загрузка истории из JSON файла.
  - `save_history() -> None`: Сохранение истории в JSON файл.
  - `delete_history() -> None`: Очистка истории.

## Возможности использования приложения:
- Добавление доходов и расходов с указанием суммы, категории и даты.
- Просмотр диаграммы доходов и расходов.
- Очистка истории операций.
- Автоматическое сохранение и загрузка истории в JSON файл.
- Возможность просмотра общей статистики за конкретный месяц.
- Возможность просмотра категорий операций и их процентного соотношения к общей сумме операций.

## Установка библиотек и запуск приложения
- Установка библиотеки `matplotlib` - `pip install matplotlib`
- Запуск - `python main.py`
