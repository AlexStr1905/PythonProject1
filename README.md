# Приложение по учету доходов, расходов и налогов
## Описание
#### Данное приложение предназначено для учета доходов, расходов и налогов. С его помощью пользователь может легко отслеживать свои финансы, анализировать свои траты и оптимизировать свои налоговые выплаты.
## Возможности
* #### Добавление доходов и расходов
* #### Просмотр и редактирование списков доходов и расходов
* #### Подсчет налогов 
* #### Генерация отчетов и статистики по финансовым операциям
## Требования к установке
* #### Python 3
* #### Библиотека pandas
* #### Библиотека numpy
* #### Библиотека matplotlib
## Установка
1. #### Клонировать репозиторий на свой компьютер
2. #### Установить необходимые библиотеки с помощью команды `pip install 'library'`
3. #### Запустить приложение командой `python main.py`
## Использование
1. #### Запустить приложение
2. #### Добавить доходы и расходы
3. #### Посмотреть налоговые выплаты
4. #### Просматривать отчеты и статистику
